# Atelier de création anniversaire / BD

[Sommaire](../README.md) · [Questionnaire](albert.md) · [Liseuse publiée](liseuse.md)

Le dossier anniversaire est principalement un espace de production : planches, références, retouches, couvertures, dossiers imprimeur, scripts et documents de validation. `anniversaire/animation-3d/apercu-anime-v1.html` est un aperçu autonome ; `anniversaire/site-bd-albert` contient la chaîne de fabrication de la liseuse. Ce n'est pas une base de données « BD » : ici BD désigne la bande dessinée.

La collecte structurée de souvenirs et de fiches personnages relève de l'application albert_65ans et de son schéma Supabase, décrits séparément. Les originaux de création et sauvegardes privées ne sont pas des tables ni des artefacts web destinés automatiquement à la publication.

Les AGENTS.md anniversaire et albert_65ans fixent des consignes de références, style et préservation des versions ; elles ont été lues. Aucune création d'image ni retouche n'a été réalisée. La chaîne prepare.py/encrypt.cjs sert à produire la liseuse protégée ; seuls les fichiers de publication chiffrés sont prévus sous `/BD/albert/`.

Pas de backend ni manifeste d'installation global de l'atelier identifié. Les prérequis dépendent du script (notamment Python/Pillow, Node et outils de montage). La publication générale par copie large peut inclure des fichiers de travail versionnés : le périmètre public doit être confirmé. Aucun inventaire du contenu privé des photos/souvenirs n'est recopié dans cette documentation.
